# Privacy Policy — Relay

**Last updated:** 26 November 2026
**Developer:** Taufik Hidayat (independent developer, Indonesia)
**Contact:** harimauameh12@gmail.com
**App:** Relay — Jira handover agent (Atlassian Forge app, built for Codegeist 2026)

## What Relay does

Relay helps teams hand over work in Jira when someone is away: it lists open
issues whose assignee is away, suggests the best successor, and reassigns the
issue with a handover comment.

## What data Relay processes

Relay only processes data inside the Atlassian site where it is installed:

- Jira issue data: issue keys, summaries, statuses, priorities, and assignee
  account IDs — read through the Atlassian Forge APIs to find orphaned work
  and rank successors.
- Away flags: an assignee's away status and return date, as set by a site
  admin inside the app. These are stored in Atlassian Forge storage (KVS),
  which lives on Atlassian infrastructure.

## What Relay does NOT do

- Relay sends no data to any external server. There are no third-party
  analytics, trackers, or advertising services.
- Relay does not sell, share, or disclose your data to anyone.
- Relay does not store data outside Atlassian infrastructure.

## Data retention and deletion

Away flags are kept only while they are set; an admin can clear them at any
time from inside the app. Uninstalling Relay from a site removes the app's
access to that site's data.
